{% comment %} Analytics core, inline in on every page (also when GA is off). window.mrTrack(name, params) / window.mrTrackEcommerce(name, payload) are the only way page code talks to GA4 / GTM. They: • are safe without GA (local/dev): events go to window.mrAnalyticsLog only; • strip personal data (keys like email/phone/name, e-mails and phone-like digit runs inside strings) and cut strings to GA4's 100 characters; • in gtag mode call gtag('event'), in GTM mode push the GTM shape; • with {beforeUnload: true} park the event in sessionStorage when gtag.js has not loaded yet (a click that navigates away), and replay it on the next page, so fast clicks are not lost. Also here, so they cover the whole page life and pages without a bundle: js_error (window.onerror + unhandledrejection, deduped, max 5 per page) and web vitals (LCP, CLS, INP from PerformanceObserver, one web_vitals event per metric when the page is hidden). The client never sends `purchase`: it goes server-side (project/ga4_mp.py). {% endcomment %}
