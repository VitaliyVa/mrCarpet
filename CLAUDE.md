# mrCarpet: правила проєкту

Django 4.2 магазин килимів, https://mrcarpet24.com. Деплой: push у `main` → GitHub Actions → `migrate` на сервері.
Довідники (локально, `docs/` у .gitignore): `docs/seo.md`, `docs/marketing-plan.md`.

## Тексти для покупців
- Тільки українською. Просто і тепло, «як домогосподарка пише для домогосподарки».
- Короткі речення, звичайні слова, без наукового тону, без довгих тире (—).
- Факти (розмір, матеріал, ціна, країна) тільки з бази чи живого сайту, нічого не вигадувати.
- Фото до статей: тільки вільні ліцензії (Unsplash, Pexels, CC0) або згенеровані.

## Мова сайту
- Російської версії немає і не робимо. Рос. запити закриваємо Google Ads (мови: усі) і українськими текстами
  зі словами, які пошук зіставляє між мовами (килимок, поліпропілен, ворс, джутова основа). Рос. фрази в текст не вставляти.

## SEO
- Canonical / og:url / sitemap тільки з `project.seo_urls` (`absolute_site_url`, `canonical_url`), ніколи з `request.get_host()`.
- Пошук і фільтри (`?q=`, сортування, фільтри) мають `noindex, follow`; трекінгові мітки (gclid, utm_*) не впливають на індекс.
- Приватні сторінки завжди noindex.

## Прод-база
- Немає SSH для агентів. Зміни даних у проді тільки ідемпотентними data-міграціями за slug, без видалень,
  і їх готує/перевіряє головна сесія, не субагенти.
